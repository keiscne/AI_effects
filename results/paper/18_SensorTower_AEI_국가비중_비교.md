## 초록

report 17은 "모든 제품의 1인당 메시지 수와 업무 비중이 같다"는 두 가정 아래 Sensor Tower 이용자 수로 국가별 메시지와 업무용 메시지를 만들었다. 본 문서는 이 국가 분포를 Anthropic Economic Index(AEI)의 Claude.ai 국가별 대화 비중과 18개국 안에서 비교해 두 가정을 점검한다. AEI 자료는 release 2026-03-24(2026년 2월 1주)와 release 2026-06-26(2026년 4월·5월)이다. 결과는 세 가지다.

1. **국가 비중**: Sensor Tower 8개 제품 메시지 비중과 AEI 비중은 크게 다르다. 상관은 0.48–0.51, 비유사도 지수 D는 35–38%p다. 미국은 AEI에서 32–38%로 Sensor Tower(13.6–14.7%)의 2.3–2.6배이고, 인도는 AEI에서 10–11%로 Sensor Tower(33–34%)의 3분의 1이다. Sensor Tower의 **Claude 이용자** 비중과 비교하면 상관이 0.64–0.74로 오르고 D가 25–28%p로 줄어든다. 즉 차이의 4분의 1–3분의 1은 제품 구성으로 설명된다(Claude 이용자는 고소득국에 치우침). 남은 차이는 Claude 이용자 1인당 대화가 고소득국에서 많고 신흥국에서 적다는 뜻이다. 따라서 "1인당 메시지 수가 국가 간에 같다"는 가정은 지지되지 않는다.
2. **업무 비중 수준**: AEI의 Claude 업무용 대화 비중(18개국 가중 42–44%)은 Signals의 ChatGPT 업무 비중(32–33%)보다 10–11%p 높다. 18개국 평균 차이는 12–14%p다. 국가 간 상관은 −0.27–0.04로 사실상 없다. "모든 제품의 업무 비중이 ChatGPT와 같다"는 가정은 Claude에 대해서는 수준과 국가 순서 모두에서 맞지 않는다.
3. **업무용 국가 비중**: 업무 비중의 국가 간 차이는 국가 규모 차이보다 작다. 그래서 업무용 국가 분포의 비교 결과는 전체 분포와 거의 같다(D 35–37%p, Claude 이용자 기준 24–28%p).

## 1. 목적

report 17의 국가별 메시지 수는 두 가정 위에 서 있다.

- (A1) 이용자 1인당 메시지 수가 제품·국가·시점에 걸쳐 같다.
- (A2) 업무용 비중이 제품 간에 같고, 국가별 ChatGPT 값(Signals)과 같다.

두 가정 아래 국가의 메시지 비중은 이용자 비중과 같고, 업무용 메시지 비중은 "이용자 비중 × ChatGPT 업무 비중"에 비례한다.

AEI는 Claude.ai 대화 표본으로 국가별 대화 비중과 업무용 대화 비중을 공개한다(Massenkoff et al. 2026a, 2026b). 제품은 Claude 하나지만 **실제 사용량의 국가 분포**를 보여 준다. 그래서 Sensor Tower 이용자 분포와 비교하면 두 가정이 어디서 어긋나는지 알 수 있다. 비교는 두 축으로 한다.

- **제품 구성**: Sensor Tower 8개 제품 합계 대 Sensor Tower Claude 이용자. 둘의 차이는 제품 구성 효과다.
- **사용 강도**: Sensor Tower Claude 이용자 대 AEI Claude 대화. 둘의 차이는 국가별 1인당 사용 강도 차이와 두 자료의 측정 차이다.

## 2. 자료와 비교 지표

### 2.1 Anthropic Economic Index

| release | 기간·표본 | 사용 변수 |
|---|---|---|
| 2026-03-24 | 2026-02-05~02-11(1주). Claude.ai 대화 표본 100만 건. 177개국 + 국가 미상(`NONE`, 0.23%) | `usage_count`, `usage_pct`(= 건수 ÷ 100만), `use_case_pct`(work) |
| 2026-06-26 | 2026-04, 2026-05(월별). 건수 없음, 소수 둘째 자리. 공개 국가 114개(4월)·121개(5월), 공개 국가 합계 82.0%·87.5% | `overall`의 `usage_pct`, `use_case_work_pct` |

- 범위는 Claude.ai(Free·Pro·Max, 06-26은 Cowork 포함)다. API와 Claude Code는 빠진다.
- `usage_pct`의 분모는 Claude.ai 전 세계 대화다(공개되지 않은 국가 포함). 공개 기준(표본 하한)에 못 미친 국가는 행이 없다. 18개국은 세 기간 모두 공개되어 있다.
- 업무용 비중은 use case 분류(work, personal, coursework) 중 work의 비중이다. 분모는 그 국가 대화 전체다(03-24에서 건수로 확인).
- 원자료는 `code/01_import_aei_country_usage.do`가 `data/proc/usage/anthropic_economic_index/aei_claude_ai_country_usage.{csv, dta}`로 정리한다. 03-24는 ISO 3166-1 alpha-2, 06-26은 alpha-3 코드를 쓴다.

### 2.2 Sensor Tower 기반 값(report 17)

- **8개 제품 메시지**: `sensortower_work_messages_by_country_monthly`의 `messages`, `work_messages`, `work_share`(Signals). (A1) 때문에 메시지 비중은 8개 제품 이용자 비중과 같다.
- **Claude 이용자**: `sensortower_share_within_product_monthly_long`의 Claude `unique_users`. (A1) 아래 Claude 메시지 비중과 같다.
- **Claude 업무용**: Claude 이용자 × Signals 국가별 업무 비중. 제품 구성 차이를 뺀 업무용 비교에 쓴다.

### 2.3 비교 지표

두 자료는 분모 범위가 다르다. Sensor Tower에서 18개국은 25개 시장 이용자의 약 90%이지만, AEI에서 18개국은 Claude.ai 전 세계 대화의 59–63%다(표 1 마지막 행). 그래서 모든 비교는 **18개국 합계를 100으로 다시 정규화한 비중**으로 한다.

- 비유사도 지수 D = ½ Σ |s_A − s_B|(%p). 두 분포를 같게 만들려면 옮겨야 하는 비중이다. 0이면 같고 100이면 완전히 겹치지 않는다.
- 그 밖에 Pearson 상관과 Spearman 순위 상관을 본다.

**기간 짝짓기**: AEI 03-24(2026년 2월 1주)는 Sensor Tower 2026년 2월(월간)과 짝짓는다. AEI 06-26의 4월·5월은 같은 달과 짝짓는다. 국가는 Sensor Tower 시장명 → ISO2/ISO3 대응표로 맞춘다.

**측정 단위 차이**: Sensor Tower 기반 값은 **메시지**(Chatterji 기준), AEI는 **대화**다. 국가마다 대화당 메시지 수가 다르면 그것도 비중 차이의 일부가 된다. 이를 따로 식별할 자료는 없다.

**결과**

1. **8개 제품 기준으로는 크게 다르다.** 미국은 AEI에서 32–38%로 Sensor Tower의 2.3–2.6배, 인도는 10–11%로 0.31–0.34배다.
   - AEI가 Sensor Tower보다 큰 나라는 미국·호주·캐나다·영국·프랑스·한국(1.8–3.5배) 등 고소득국이다.
   - 작은 나라는 인도·브라질·인도네시아·멕시코·튀르키예·베트남(0.3–0.6배) 등 신흥국이다.
2. **제품 구성이 차이의 일부를 설명한다.** Sensor Tower 안에서도 Claude 이용자는 8개 제품 전체보다 미국(18–24% 대 13.6–14.7%)과 유럽에 치우쳐 있다. 브라질·인도네시아·멕시코·튀르키예에서는 적다. Claude 이용자 기준으로 바꾸면 D가 35–38%p에서 25–28%p로 줄어든다(표 7).
3. **그래도 사용 강도 차이가 크다.** Claude 이용자 대비 AEI 비율은 다음과 같다.
   - 높은 나라: 미국 1.6–1.8, 호주 1.9–2.4, 한국 1.9–2.2, 영국·프랑스·캐나다 1.5–1.8
   - 낮은 나라: 인도 0.35, 튀르키예·브라질 0.58–0.72

   인도는 Sensor Tower Claude 이용자의 약 3분의 1(30–33%)을 차지하지만 AEI 대화로는 10–11%다. 즉 **Claude 이용자 1인당 대화 수가 고소득국에서 신흥국보다 몇 배 많다**. 이는 Sensor Tower 이용자 추정의 국가별 측정 오차일 수도 있다. 어느 쪽이든 "이용자 수 × 공통 1인당 메시지"로 국가 사용량을 만들면 신흥국은 과대, 고소득국은 과소 추정된다.
4. **시점에 따라 크게 바뀌지 않는다.** 세 기간의 상관과 D가 비슷하다. 다만 미국 비중은 2026년 2월(1주)에 37.7%로 가장 높고, 4–5월로 갈수록 낮아진다.

   - 국가별로는 인도네시아를 뺀 17개국에서 AEI가 높다. 차이는 튀르키예·베트남·브라질·아르헨티나에서 특히 크다(약 18–27%p).
2. **국가 순서도 맞지 않는다.** 두 비중의 국가 간 상관은 −0.27–0.04, 순위 상관은 −0.30–0.17이다(표 7).
   - 튀르키예는 Signals에서 업무 비중이 가장 낮지만(18–20%) AEI에서는 40–45%로 중간이다.
   - 인도네시아는 Signals에서 높지만(37–42%) AEI에서는 가장 낮다(29–32%).
3. **분류 기준 차이를 감안해야 한다.** Signals의 `work_related`는 메시지 단위 이진 분류이고, AEI의 use case는 대화 단위 3분류(work/personal/coursework)다. 분류기도 다르다. 따라서 수준 차이의 일부는 정의 차이일 수 있다. 그러나 국가 순서가 무관하다는 점은 정의 차이만으로는 설명하기 어렵다. 제품별 이용자층 구성이 국가마다 다르다는 것을 시사한다.

이 결과는 (A2)가 Claude에 대해서는 맞지 않는다는 뜻이다. report 17은 Claude 몫의 업무용 메시지를 과소 추정하며, 그 정도는 국가마다 다르다.

## 7. 함의

1. **report 17 국가별 메시지의 해석.** 이용자 수 기반 국가 메시지는 "이용자 분포"에 가깝고, 실제 사용 분포와는 상당히 다를 수 있다. 적어도 Claude에서는 사용량이 고소득국에 훨씬 집중되어 있다. 국가 비교에 쓸 때는 신흥국 과대·고소득국 과소 가능성을 명시해야 한다.
2. **보정 방향.** 두 가지를 생각할 수 있다.
   - Claude 몫은 AEI 국가 비중으로 Claude Worldwide 메시지를 직접 나눈다.
   - 국가별 1인당 사용 강도 지표(AEI `usage_per_capita_index`, Sensor Tower 앱 세션·웹 방문의 국가별 값)로 (A1)을 국가별로 완화한다.

   ChatGPT는 Signals가 국가별 메시지 비중 대신 분기별 순위(`share_of_messages_by_country_quarter_rank.csv`)만 공개하므로, 순위 수준의 점검만 할 수 있다.
3. **업무 비중.** 제품별로 업무 비중을 달리 두는 것이 바람직하다. 현실적인 방식은 Claude에는 AEI 국가별 `use_case_work_pct`를, ChatGPT에는 Signals를 쓰고, 나머지 제품은 범위를 두어 민감도를 보이는 것이다.

**한계**

- AEI 03-24는 1주 표본이다.
- AEI 06-26 비중은 소수 둘째 자리로 반올림된 값이라 작은 나라에서 상대 오차가 크다.
- AEI는 대화, Sensor Tower 기반 값은 메시지 단위다.
- AEI는 Claude.ai만 포함하고 API는 포함하지 않는다.
- Sensor Tower의 Claude 이용자는 독립 앱+웹 True Audience다. AEI의 Claude.ai(웹·앱)와 범위가 대체로 같지만 정확히 같지는 않다.
