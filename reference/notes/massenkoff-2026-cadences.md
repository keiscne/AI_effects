## One-line Summary

Anthropic Economic Index 6번째 보고서(V6). 시간단위(hourly) 프라이버시 보존 표집을 처음 도입해 Claude 사용의 요일·시간대 리듬(주말 개인용 급증, 세금신고 마감 급증 등)을 문서화하고, 대화 산출물(artifact)을 30여개 범주로 분류해 고임금 직업일수록 더 많은 토큰을 소비함(2.07배, 상위 vs 하위 임금삼분위)을 실증하며, 2026년 4월 개시한 Anthropic Economic Index Survey(약 9,700명 연계표본)로 자동화적으로 Claude를 사용하는 이용자일수록 향후 자신의 임금·고용안정성에 대해 더 낙관적임을 최초로 보고.

## Key Contributions

- 시간단위(hourly) 표집이 가능한 신규 프라이버시 보존 데이터 파이프라인을 도입, 기존 7일 스냅샷 표본으로는 볼 수 없었던 일중·요일간 사용패턴을 처음으로 문서화 (p.3).
- 대화 산출물(artifact, 문서·설명·코드 등 30여개 범주)을 분류하는 신규 분류기를 도입해 Claude 대화의 93%에서 구체적 산출물을 식별, 용도(업무/개인/코스워크)별 산출물 구성과 토큰소비-임금의 관계를 실증 (p.9-13).
- Claude.ai/Cowork와 Claude Code 간 AI 자율성(1-5점) 수준을 비교해, 동일 산출물 유형이라도 Claude Code에서 자율성이 평균 0.37점 더 높음을 규명 (p.14-15).
- 2026년 4월 개시한 Anthropic Economic Index Survey(약 9,700명의 사용데이터 연계표본)를 이용해, 처음으로 사용자의 AI에 대한 주관적 기대·인식을 사용패턴과 직접 연결 (p.19 이하, Chapter 3).

## Methodology and Data

- Chapter 1·2: Claude.ai·Cowork 대화("Claude conversations")와 1P API를 구분해 월단위로 집계, 표본기간은 2026년 4월 10일~6월 10일(자율성 논의에서 Claude Code 세션도 동일기간 포함) (p.18 각주1).
- 임금 매핑: BLS OEWS 2025년 5월 릴리스 기준 직업별 시급 (p.18 각주1).
- 산출물 분류: 각 대화를 30여개 산출물 범주로 분류하는 신규 분류기 도입, 전체 목록은 부록에 수록(본 PDF에는 부록 본문 미포함, "Appendix: Available here"로만 명시, p.32).
- 토큰-임금 분석: 대화단위 토큰수(추론과정 포함)를 기하평균으로 집계(우측왜도가 매우 커 기하평균 사용, 중위수·모델별 비용가중 시에도 유사한 결과, 각주3)해 과업이 매핑된 직업의 시급과의 관계를 로그-로그 척도로 분석. 업무관련 대화로 한정 (p.11-13, 각주3).
- AI 자율성 비교: Claude.ai/Cowork와 Claude Code 간 자율성(1-5점)을 산출물 유형별로 비교, 모델(Opus/Sonnet)을 고정한 부분표본 비교도 병행 (p.14-15).
- 읽기수준(reading level): 각 대화의 사용자 프롬프트·Claude 응답에 대해 이해에 필요한 교육연수를 분류기로 추정, 산출물 유형별 상관관계(r=0.87) 분석 (p.16-17).
- Chapter 3: 2025년 12월 Anthropic Interviewer로 81,000명 인터뷰(선행연구)에 이어, 2026년 4월 개시한 Anthropic Economic Index Survey를 프라이버시 보존 방식으로 2026년 5월 중순~6월 초 사용데이터와 연계 — 응답자당 최대 20개 세션(Claude.ai·Cowork·Claude Code 전체 표면 반영)을 무작위 표집, 세션 5개 미만 응답자 제외, 최종 연계표본 약 9,700명 (p.18-19).

## Key Results

- 요일 리듬: Claude.ai·Cowork 대화 중 개인용 비중이 평일 약 35%→주말 50% 미만으로 급증(그림1.1), 고소득국일수록 이 변화폭이 더 큼 (p.4).
- Claude Code 주말 사용: 주말에 가장 많이 감소하는 클러스터는 백엔드아키텍처·API디버깅·데이터저장, 가장 많이 증가하는 클러스터는 AI에이전트설계·퀀트트레이딩·게이밍 (p.5).
- 일중 리듬: 뉴스요청은 오전7시, 업무서신은 오전10~11시 소폭 피크, 레시피요청은 오후6시에 평균대비 2.3배로 최대 스파이크, 수면조언 요청은 새벽시간대 집중 (그림1.2, p.5-6).
- 세금신고 스파이크: 미국 세금신고 마감(4월15일) 직전인 4월14일에 세금관련 대화클러스터가 평상시(5월 평균) 대비 8배로 급증, 4월15일에도 유사수준 유지 후 4월16일 급락 (그림1.4, p.7).
- 산출물 분류: 전체 대화의 93%에서 산출물 식별. 최다 산출물은 설명(17%)·문서및보고서(15%)·가이던스(11%) (그림2.1, p.9).
- 용도별 산출물: 창작글쓰기·가이던스·레시피의 80%+가 개인용. 마케팅콘텐츠(80%)·블로그/기사(81%)·데이터베이스쿼리작성(82%)은 업무관련 비중 최고 (그림2.2, p.10).
- 업무 대화 산출물: 문서및보고서(20%)·설명(9%)·이메일초안(7%)·분석및요약(6%) 순. 코스워크는 문서및보고서(21%)·설명(20%)·교육자료(11%)·학술논문(6%). 개인용은 문서 6%에 불과, 설명(25%)·추천(22%)이 최다 (p.10-11).
- 토큰-임금 관계: 마케팅매니저(시급 $80)는 편집자(시급 $37)보다 약 2배 임금이나 매핑 대화의 토큰소비는 약 2.5배(그림2.3, p.12). 상위임금 직업 매핑 대화는 하위임금 대비 아웃라이어도 존재(약사 $68 vs 통계보조원 $24이나 토큰소비는 약사가 1/20 수준) (p.12).
- 표2.4: 상위임금삼분위 매핑 대화는 하위삼분위 대비 토큰소비 2.07배, Claude 산출량 1.34배, 사용자턴수 1.53배, extended thinking 활성화 비율 34% vs 31% (p.13).
- 토큰소비의 약 44%가 산출물 구성(mix) 차이로 설명됨 — 고임금 직업일수록 연산집약적 산출물(앱 구축 등, 중위수 대비 3배 이상 토큰)을 더 많이 생성 (p.13).
- AI 자율성: 31개 산출물 유형 중 26개에서 Claude Code가 chat/Cowork보다 자율성이 높음, 전체 평균차이 0.37점 — 이 중 약 2/3는 동일 과업이 더 위임적으로 수행됨에서, 나머지 1/3은 산출물 구성 차이에서 기인 (p.14). 블로그작성의 경우 chat/Cowork 중위 대화는 13회 왕복, Claude Code 중위 세션은 인간프롬프트 1회 (p.14-15).
- 모델효과 통제: Claude Code는 54%가 Opus로 서비스(chat/Cowork는 10%)되나, Sonnet만 비교해도 Claude Code가 0.26점 더 높은 자율성을 보여 "제품 자체"가 모델보다 중요함을 시사 (p.15).
- 자율성-토큰 상관: chat/Cowork에서 산출물별 평균자율성과 중위토큰사용의 상관계수 r=0.68 (p.15).
- 읽기수준: 학술논문 산출 평균쿼리는 이해에 16년+(학사수준) 교육 필요, 이 중 15%는 박사수준(20년+). 프롬프트-응답 읽기수준 상관 0.87, Claude 응답이 프롬프트보다 평균 약 1년 더 높은 수준(이미지/그래픽 +2.6년·게임 +1.9년·앱/웹사이트 +1.7년으로 격차 최대, 블로그 -0.1년·학술논문 +0.0년·이메일 +0.3년으로 격차 최소) (p.16-17).
- Survey 응답자 구성: 컴퓨터·수학직이 전체 응답의 약 30%(미국고용의 4%에 불과), 경영직 23%(고용비중 7%, 세션비중은 4%에 불과) — 관리직은 관리 자체가 아닌 다른 업무에 Claude를 사용함을 시사 (그림3.1, p.20-21).
- 노출 인식: 응답자의 약 60%가 "AI가 오늘 할 수 있는 업무 비중"보다 "12개월 후 할 수 있는 비중"에 더 높은 구간을 선택, 3분의1 이상이 12개월 후 "대부분 또는 거의 전부" 예상 (그림3.2, p.21-22).
- 보고노출 vs 관측/이론노출: 보고노출(reported exposure)은 관측노출·이론노출 모두와 양의 상관이나, 관측/이론노출이 높은 직업이라고 향후 12개월 기대증가폭이 더 크지는 않음(두 적합선이 평행) (그림3.3, p.22-23).
- 국가·경력별 인식: 고소득국일수록 보고노출이 약 10%포인트 낮음(GDP 1인당 대비), 경력 15년 이상 근로자도 신입 대비 약 10%포인트 낮은 보고노출(그림3.4, p.23-24) — 반면 향후 12개월 기대증가폭은 GDP·경력과 거의 무관 (p.24).
- 자동화사용-인식: 자동화 비중이 높은 이용자일수록 보고·기대노출 모두 더 높음(그림3.4 우패널, p.25).
- 고용전망 인식: 응답자의 1/3 이상이 향후 12개월내 (본인/동료/후배/상사 포함) 직무책임 대폭변화가 "가능성높음/매우높음"이라 응답, 10%는 본인 실직가능성을 "가능성높음/매우높음"으로 평가(미국 연환산 비자발적 이직률 약 13.4%보다 낮은 수준이나 응답자군이 안정적 지식노동자에 편중된 점을 고려하면 시사적) (그림3.5, p.25-26, 각주9).
- 자동화-낙관성: 자동화비중이 높은 이용자일수록 임금·고용안정성·구직가능성 등 6개 차원 모두에서 향후 긍정적 영향을 더 많이 기대, 효과크기는 임금·구직가능성에서 최대(그림3.6, p.26-27).
- 생산성 자기보고: 속도(86%)·범위(82%)·품질(69%) 향상을 보고한 비율이 다수, 27%는 비용절감 효과 보고. 68%는 "AI로 더 많이 배운다", 57%는 "AI가 내 스킬가치를 높였다"고 응답 — 자동화비중이 높을수록 스킬가치상승 응답비율은 상승하나 학습응답비율은 거의 변화없음(그림3.7, p.27-28).
- 성별 차이: 여성은 연계표본의 12%에 불과, 직업통제 후에도 여성은 Claude Code 세션비중이 0.24표준편차(6.3%p) 낮고 자동화비중이 0.33표준편차(7.3%p) 낮으며, chat 총활성시간은 남성보다 더 높음(협업적 참여 시사) (그림3.8, p.29).
- 희망 테마(자유응답): 절반 이상이 "AI와의 협업으로 의미있는 일 유지" 등 증강 테마, 절반 이상이 지루한 업무 자동화·여가시간 확대 테마, 약 1/3이 "이득의 광범위한 공유" 테마를 언급 (그림3.9, p.30).

## Limitations and Future Work

- 저자가 명시: Survey는 일반인구를 대표하지 않으며(무작위 Claude 이용자 표본, 응답완료에 선택편향 가능, 저빈도 이용자 필터링), 응답자 구성이 컴퓨터·수학직·관리직에 편중됨 (p.20).
- 이항구간(binned) 응답척도로 인해 보고/기대노출 기울기가 0쪽으로 편향되는 한계를 인정, 이분지표(60% 이상 여부)로 재추정해도 정성적 패턴(양의 기울기·평행선)이 견고함을 확인 (각주4, p.24).
- 자동화사용-낙관성 관계가 선택효과(원래 AI에 열광적인 사람이 더 많이 위임)로 설명될 가능성을 배제하지 못하나, Claude.ai 가입기간(tenure, 열광도 프록시)을 통제해도 추정치가 유의하게 변하지 않음을 확인 (p.27).
- 학습효과 관련: 자기보고 방식이므로 "학습한다"는 응답과 실제 스킬향상 간 괴리, 즉 스킬가치 상승·학습보고와 동시에 스킬퇴화(skill atrophy)가 발생할 가능성을 데이터가 배제하지 못함을 명시 (p.28).
- 결론에서 AI간 상호작용이 늘어나면 향후 분류가 더 어려워질 수 있음(인간이나 단순분류기가 이해하기 어려운 방식의 AI-AI 교환 가능성)을 향후 과제로 제시, 궁극적으로 Claude의 경제적 영향은 사용로그뿐 아니라 고용·생산성 등 거시지표로 나타날 것이라는 점을 강조 (p.31-32).

## Glossary

- **Claude conversations**: Claude.ai·Claude 데스크톱앱의 chat 및 Cowork 탭에서 이뤄진 대화를 통칭. Claude Code·1P API 트래픽과는 별도로 보고 (p.4 각주2).
- **산출물(artifact)**: 대화에서 Claude가 생성하는 주된 결과물(문서·설명·코드·학술논문 등 30여개 범주로 분류) (p.9).
- **AI 자율성(AI autonomy)**: Claude가 과업 수행 중 스스로 결정을 내리는 정도(1=전무~5=매우높음), 자동화(automation, 사용자가 위임하는 정도)와는 별개 차원 — 예: "이 문단을 프랑스어로 번역해줘"는 고자동화·저자율성 (p.19-20).
- **Anthropic Economic Index Survey**: 2026년 4월 개시된 설문으로, 응답자의 실제 Claude 사용데이터(최대 20개 세션 무작위표집)와 프라이버시 보존 방식으로 연계됨. 최종 연계표본 약 9,700명 (p.19).
- **관측노출(observed exposure) 대 보고노출(reported exposure)/기대노출(anticipated exposure)**: 관측노출은 실제 Claude 사용데이터 기반 직업별 과업커버리지, 보고노출/기대노출은 설문응답자가 직접 응답한 "AI가 오늘/12개월후 할 수 있는 업무비중" (p.21-22).
